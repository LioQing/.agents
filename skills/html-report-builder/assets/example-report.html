05 · SLO

Error-budget accounting

For a 99.9% monthly availability objective, the allowed bad-request ratio is \(1-SLO\). Budget consumption compares observed failures with that allowance.

\[\text{Budget used}=\frac{\text{failed requests}}{\text{total requests}\times(1-SLO)}\times100\%\]

August recorded 35,002 failures out of 81,400,000 requests. At a 99.9% objective, the allowance is 81,400 failures: 43% used and 57% remaining. Checkout contributes 61% of the observed failures.

06 · Implementation

Bound retries by time and count

The retry must fit inside the request deadline and preserve the payment idempotency key.

Python
import asyncio


async def charge_with_retry(gateway, payment, *, deadline_ms=800):
    # Python 3.11+: the deadline covers both attempts together.
    async with asyncio.timeout(deadline_ms / 1000):
        for attempt in range(2):
            try:
                return await gateway.charge(
                    payment,
                    idempotency_key=payment.order_id,
                    timeout_ms=deadline_ms // 2,
                )
            except GatewayTimeout:
                if attempt == 1:
                    raise

error

Duplicate-charge risk: retries require gateway support for the same idempotency key. The adapter must also supply GatewayTimeout; the caller handles an exhausted deadline or retry through the circuit breaker.

07 · Notes

Methodology and limits

info

Source: embedded fictional Northstar fixture. August counts reconcile to the displayed availability and error budget. Weekly latency values remain available beside the chart.

Measurement windowexpand_more

The fixture defines seven weekly latency samples ending 13 September and separate August request totals. Synthetic checks and client-cancelled requests are excluded from the scenario. Do not compare these windows as though they were identical.

Percentile calculationexpand_more

Each weekly percentile represents pooled successful server-side request durations. Endpoint percentiles are separate measurements; averaging endpoint or regional percentiles would not recover the service percentile.

Important limitationexpand_more

All measurements, rollout events, and completed checks are fictional. They form one internally consistent scenario, not production evidence. The cache rollout coincides with lower latency; causation and region-level results are not established.
