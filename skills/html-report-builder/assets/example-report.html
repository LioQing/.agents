06 · Quantitative definitions

Inline and display mathematics

Let \(L_1\) be the first measurement and \(L_4\) the last. The proportional reduction is \(r\); ordinary currency such as $100 is not treated as math.

\[r = \frac{L_1-L_4}{L_1}\times100\%\]
\[\begin{aligned}L_1-L_4 &= 236-184 = 52\text{ ms}\\r &= \frac{52}{236}\times100\% \approx 22.03\%\end{aligned}\]
\(L_1\), \(L_4\)
Illustrative p95 latency in milliseconds at weeks 1 and 4.
\(r\)
Percentage reduction relative to the first value, not percentage points.

Plain-language equivalent: subtract 184 from 236, divide the 52 ms difference by 236, then multiply by 100. The result is about 22.03%.

07 · Reproducible calculation

A labeled, copyable code block

The sample calculates the percentage in the preceding section. It has no network or payment side effects.

Python · reduction.py
def reduction_percent(first_ms, last_ms):
    if first_ms <= 0:
        raise ValueError("first_ms must be positive")
    return (first_ms - last_ms) / first_ms * 100

result = reduction_percent(236, 184)
print(f"{result:.2f}%")  # 22.03%
